# PokéDB Data

This branch contains the validated JSON datasets generated by the
[`PokéDB`](https://github.com/zhenga8533/pokedb) package. The complete corpus
is regenerated weekly from structured [PokéAPI](https://pokeapi.co/) data.

## Data contract

- The current format is schema version 3.
- Every `genN` directory is a cumulative catalog of resources introduced by or
  before that generation.
- Generation output is not a claim that every resource is obtainable in every
  game. Version-group maps identify game-specific values where PokéAPI exposes
  them.
- Structural field names use `snake_case`. PokéAPI identifiers retain their
  canonical kebab-case spelling.
- `null` means unavailable, inapplicable, or not versioned by PokéAPI. Empty
  collections mean the modeled mechanic applies but has no entries.

PokéAPI does not provide complete item-introduction history. Item catalogs use
structured game-index evidence plus item references from generated machines,
held items, and evolution conditions. They are referentially complete, but do
not claim to enumerate every unreferenced item available in each historical
game.

## Layout

```text
genN/
|-- index.json
|-- ability/
|-- item/
|-- move/
`-- pokemon/
    |-- default/
    |-- variant/
    |-- transformation/
    `-- cosmetic/
```

Every `index.json` contains source and generation metadata, stable resource
summary arrays, and counts. All resource keys are present even when their list
is empty.

## Static API

Use `https://raw.githubusercontent.com/zhenga8533/pokedb/data` as the base URL.

- Generation 9 index:
  [`/gen9/index.json`](https://raw.githubusercontent.com/zhenga8533/pokedb/data/gen9/index.json)
- Generation 9 Pikachu:
  [`/gen9/pokemon/default/pikachu.json`](https://raw.githubusercontent.com/zhenga8533/pokedb/data/gen9/pokemon/default/pikachu.json)
- Generation 9 Ice Stone:
  [`/gen9/item/ice-stone.json`](https://raw.githubusercontent.com/zhenga8533/pokedb/data/gen9/item/ice-stone.json)

See the project [API documentation](https://github.com/zhenga8533/pokedb/wiki/API-Documentation)
and [data model](https://github.com/zhenga8533/pokedb/wiki/Data-Model) for the
full contract.

## Compatibility

Schema versions 1 and 2 are incompatible with schema version 3. Consumers
should read `metadata.schema_version` from the generation index before loading
resource files.
